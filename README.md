## ✨ About me

I'm a frontend developer who enjoys building clean, scalable interfaces and turning complex requirements into smooth user experiences.

- 💻 Working across frontend, backend, mobile, and interactive 3D experiences.
- 🧩 Interested in reusable components, consistent design, and maintainable architecture.
- ⚡ Focused on responsive layouts, performance, and accessible experiences.
- 🌱 Exploring better ways to manage state, integrate APIs, and ship reliable products.

## 💡 What I work with

- **Frontend development:** Building responsive interfaces with React, Next.js, and Vue.js.
- **Full-stack development:** Creating web applications with the MERN stack and NestJS.
- **Mobile development:** Building cross-platform interfaces with Flutter.
- **Interactive 3D:** Creating web-based 3D experiences with Three.js and React Three Fiber, with Blender in the creative workflow.
- **Engineering practices:** Reusable components, state management, REST API integration, and performance-focused UI.
