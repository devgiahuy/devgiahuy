## 💡 About Me

I’m a **Frontend Developer** passionate about building responsive, high-performance user interfaces using **React**, **TypeScript**, and modern frontend engineering practices.

Currently, I’m developing the **GreenWheel – EV Station-Based Rental System** frontend, focusing on:

- Clean and scalable React architecture
- Reusable UI components & design consistency
- Optimized state management (Zustand / React Query)
- Authentication & secure API integration
- High-performance rendering & smooth UX
- Fully responsive layouts across devices
