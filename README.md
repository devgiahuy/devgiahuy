## 👨‍💻 A little about me

I'm a frontend developer who loves turning ideas into interfaces that feel good to use. I care about the details: clean components, smooth interactions, responsive layouts, and code that stays easy to build on.

```text
Frontend    →  React · Next.js · Vue

Mobile      →  Flutter
```
